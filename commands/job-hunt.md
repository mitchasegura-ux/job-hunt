# /job-hunt - Search, screen, and build application packets

Invoke the `job-hunting` skill and follow its **Search and build** section.

`$ARGUMENTS` may narrow the run. Examples: `last 3 days`, `AV track only`,
`Portland and Salem`, `remote`. With no arguments, run the full configured
matrix across all tracks and locations.

Read `references/search-method.md` before searching if it is not already in
context.

Do not build packets before reporting the shortlist with odds. The candidate
should get the chance to say "skip that one" before you spend the effort.
